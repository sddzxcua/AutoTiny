## 🎯 Что нового в v2.0 

1. **Автоопределение роутера:**
   - Быстрое сканирование сети (ARP / ICMP ping) на типовых адресах (`192.168.1.1`, `192.168.0.1`, `192.168.31.1`, `192.168.88.1`).
   - Определение MAC-адреса и производителя по базе OUI (Xiaomi, TP-Link, Keenetic, MediaTek, ASUS).

2. **Обогащённые профили устройств (JSON в папке `configs/`):**
   - Профили вынесены в отдельные файлы для лёгкого добавления через PR.
   - Поддерживают IP сервера, шлюз, имя файла прошивки, модель, таймауты и пошаговые инструкции по входу в recovery mode.

3. **Интерактивный мастер «что делать руками»:**
   - Пошаговый чек-лист действий с живым отслеживанием состояния:
     `Ожидание запроса от роутера` ➔ `Запрос получен` ➔ `Идёт передача` ➔ `Успешно завершено!`.

4. **Живой прогресс и метрики передачи TFTP:**
   - Встроенный Python TFTP-сервер (RFC 1350 + RFC 2347/2348 `blksize`/`tsize`).
   - Настоящий прогресс-бар, расчёт скорости передачи (КБ/с, МБ/с) и подсчёт повторов блоков при потере пакетов.

5. **Проверка прошивки перед запуском:**
   - Подсчёт SHA256 и сверка с контрольной суммой профиля.
   - Оценка размера файла с предупреждением, если выбрана заглушка или неверная прошивка.

6. **Безопасное восстановление сети:**
   - Автоматический бэкап текущих настроек сетевой карты перед изменением IP.
   - Опция автоматического отката сети при выходе из программы.
   - Аварийный откат: при сбое питания или краше программа при следующем запуске предложит вернуть исходные сетевые настройки.

7. **Предполётная проверка системы:**
   - Кнопка **«🛡 Предполётная проверка»**: проверка занятости UDP порта 69, наличия активных VPN/Wi-Fi, прав администратора и фаервола.
   - Автоматическое добавление временных правил в Windows Firewall на время работы и корректное их удаление при закрытии.

8. **Встроенный UART-терминал:**
   - Выбор COM-порта, настраиваемая скорость (115200 по умолчанию).
   - Живой вывод консоли роутера при загрузке.
   - Кнопка **«⚡ Перехват U-Boot»** для мгновенного прерывания автозагрузки загрузчика.

9. **Режим Dry-Run (Тестовый прогон):**
   - Переключатель «Тестовый прогон (Dry-run)» для проверки сети и параметров без записи в память устройства.

10. **Единый отчёт для баг-репорта:**
    - Кнопка **«📋 Скопировать отчёт»**: сбор версии ОС, Python, состояния адаптера, результатов проверок и последних строк лога в один клик.

11. **Устранение критических дефектов интерфейса:**
    - Поля ввода теперь корректно обновляются даже при включённом DHCP.
    - Корректная обработка имён файлов прошивок с пробелами.
    - Возможность сохранения файлов с оригинальными именами без принудительного переименования в test.bin.

12. **Портативность и чистый дизайн:**
    - Сборка в один автономный `.exe`.
    - Тёмная палитра интерфейса, нативная тёмная рамка через Windows DWM API.
    - Отсутствие мусора в заголовке окна (строго `AutoTiny`).

## 📋 Инструкция по прошивке роутеров

1. **Подключение кабеля:** Соедините сетевую карту ПК и порт LAN1 роутера прямым Ethernet патч-кордом.
2. **Выбор профиля:** В строке «Профиль» выберите модель (например, `Xiaomi_Mi_Router_4A`) и нажмите «Загрузить».
3. **Применение IP:** Во вкладке «Сеть» нажмите «🚀 Применить к адаптеру».
4. **Файл прошивки:** Во вкладке «PXE-сервер» выберите прошивку (нажмите «📂 Выбрать файл...»).
5. **Запуск сервера:** Нажмите зелёную кнопку «▶ Запустить PXE / TFTP».
6. **Подготовка роутера:** Отключите питание роутера. Зажмите кнопку **RESET**.
7. **Включение:** Удерживая RESET, вставьте провод питания и держите 8–10 секунд, пока индикатор не замигает.
8. **Прошивка:** Отпустите RESET. Роутер запросит файл по сети. За ходом передачи следите на полосе прогресса. Дождитесь перезагрузки устройства.
